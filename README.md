## Napala

#### Framework: Nuxt JS

#### Module: Module 4 - Job Posting

#### Installation

```bash
git clone https://github.com/keeeyy23/firstattempt2026_napala.git
cd firstattempt2026_napala
npm install
npm run dev
```
